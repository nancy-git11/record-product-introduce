## 一、应用介绍

### 1.1 记刻是什么？

**记刻**是一款面向个人的健康与生活指标记录应用，可把它理解为你的「生活数据笔记本」。

你可以自由定义要追踪的内容——血压、体重、读书时长、用药习惯、心情、睡眠等——在同一款 App 里统一记录、回顾与分析，而无需为每类数据单独安装多个工具。

### 1.2 核心特点

| 特点 | 说明 |
|------|------|
| **高度自定义** | 指标名称、图标、数值类型、单位、参考区间、提醒时间均可配置 |
| **低摩擦录入** | 「今日」页一键记录，支持「同上次」快速填入 |
| **多维度回顾** | 列表、指标月历、7/30 天趋势图、年度热力图 |
| **隐私优先** | 数据默认仅保存在本机，使用 SQLCipher 加密存储 |
| **离线可用** | 核心记录与查看功能无需联网 |
| **健康数据导入** | 支持从 Apple 健康 / Health Connect 导入体重、血压、心率等 |
| **本地提醒** | 按指标配置记录提醒，支持通知点击跳转录入 |
| **数据导出** | 支持导出 CSV，便于就诊或自行备份 |

### 1.3 适用人群

- 需要长期追踪血压、体重等健康指标的用户
- 希望记录读书、运动、用药等生活习惯的用户
- 重视数据隐私、希望数据留在本地的用户

### 1.4 重要说明

记刻**不是医疗诊断工具**。应用中的参考区间由你自行设置或来源于公开资料，图表与趋势仅供个人参考，不能替代专业医疗判断。如有身体不适，请及时就医。完整说明见应用内 **设置 → 免责声明**。

## 二、如何使用记刻

### 2.1 首次使用

1. **安装并打开**记刻后，将进入引导页，了解应用的核心能力。
2. 可点击 **跳过** 或滑动浏览后 **开始使用**。
3. 进入 **选择模板** 页面，可从 6 套预设模板快速开始：
   - 高血压管理、减重追踪、阅读计划、通用健康、宝宝成长
   - 或选择 **空白开始**，自行添加指标
4. 若已有指标，应用模板时可选择 **追加** 或 **替换**（替换会归档现有指标）。

### 2.2 底部导航

记刻底部有三个主要入口：

| Tab | 名称 | 功能 |
|-----|------|------|
| 今日 | 默认首页 | 查看今日指标卡片、记录进度、快速录入 |
| 历史数据 | 日历 Tab | 按指标查看列表、月历、统计图表 |
| 设置 | — | 导出、安全、外观、指标库等 |

### 2.3 记录数据（今日页）

1. 打开 **今日** Tab，查看当天各指标卡片与完成进度。
2. 点击某张 **指标卡片**，进入该指标的录入页。
3. 或点击右下角 **+** 按钮，从列表中选择要记录的指标。
4. 录入时可：
   - 填写数值、勾选是否完成、选择时间等（依指标类型而定）
   - 使用 **同上次** 快速填入与上一条记录相同的数值
   - 添加备注、校正记录时间
5. 下拉页面可 **刷新** 今日数据。

> **提示**：若今日暂无指标，可先 **创建指标** 或 **选择模板**。

### 2.4 创建与管理指标

**创建指标**

1. 进入 **设置 → 指标库**，或从今日页空状态 / 右下角按钮进入。
2. 选择 **创建指标**，按 5 步向导完成：
   - 选择数值类型
   - 设置名称与图标
   - 配置单位、参考区间或每日目标（可选）
   - 设置是否在今日页显示
   - 配置记录提醒（可选，需通知权限）
3. 也可从 **模板** 批量添加预设指标。

**指标数值类型**

| 类型 | 适用场景 | 示例 |
|------|----------|------|
| 是/否 | 打卡类 | 是否吃药、是否运动 |
| 数值 | 单值测量 | 体重、体温 |
| 区间 | 多字段组合 | 血压（收缩压/舒张压） |
| 时长 | 累计时间 | 读书时长、运动时长 |
| 量表 | 主观评分 | 心情 1–5 分 |

**管理指标**

- 在指标库中可 **编辑**、**拖拽排序**、**归档** 指标。
- 归档后的指标不再出现在今日页，但历史记录保留。

### 2.5 回顾历史（历史数据 Tab）

1. 顶部选择要查看的 **指标**。
2. 通过分段切换三种视图：
   - **列表**：按时间轴浏览记录，支持日期范围筛选
   - **日历**：月视图，每日显示数值及相对上一有记录日的涨跌
   - **统计**：近 7 天 / 30 天折线图或柱状图，含摘要与参考区间线
3. 点击某日可查看 **日详情**，支持编辑或删除记录。
4. 从 **设置 → 年度热力** 可查看全年记录热力图。

### 2.6 设置与常用功能

| 功能 | 路径 | 说明 |
|------|------|------|
| 导出 CSV | 设置 → 导出 CSV | UTF-8 BOM 格式，可通过系统分享保存或发送 |
| 数据管理 | 设置 → 数据管理 | 查看存储占用，清除全部数据（需输入「删除」确认） |
| 健康数据同步 | 设置 → 健康数据同步 | 从 Apple 健康 / Health Connect 导入近 30 天数据 |
| PIN 锁 | 设置 → PIN 锁 | 设置 4–6 位数字 PIN，保护应用数据 |
| 通知权限 | 设置 → 通知权限 | 开启后可接收指标记录提醒 |
| 深色模式 | 设置 → 深色模式 | 切换浅色/深色主题 |
| 日历周起始日 | 设置 → 日历周起始日 | 周日或周一开始 |
| 桌面 Widget | 设置 → 桌面 Widget | 查看配置说明（需按文档完成原生配置） |
| 重新查看引导 | 设置 → 重新查看引导 | 再次浏览引导页，不会清除已有数据 |
| 免责声明 | 设置 → 免责声明 | 查看医疗相关免责说明 |

## 三、常见问题解答（FAQ）

### 入门与指标

**Q1：第一次用，应该从哪里开始？**

建议：完成引导 → 选择一套模板（如「通用健康」）→ 在今日页点击卡片完成首次记录。若需求较特殊，选「空白开始」后自行创建指标。

**Q2：可以记录哪些类型的数据？**

支持 5 种数值类型：是/否、数值、区间（如血压）、时长、量表。暂不支持自由文本、多选、照片等类型（计划在后续版本支持）。

**Q3：最多能创建多少个指标？**

MVP 版本建议活跃指标不超过 8 个（归档的不计入）。指标过多可能影响今日页浏览效率。

**Q4：应用模板时「追加」和「替换」有什么区别？**

- **追加**：在现有指标基础上增加模板中的指标。
- **替换**：将现有活跃指标归档，再导入模板指标。历史记录不会删除，但原指标不再显示在今日页。

### 记录与数据

**Q5：「同上次」是什么意思？**

录入时点击 **同上次**，会自动填入该指标上一条记录的数值，适合血压、体重等变化不大的日常记录，减少重复输入。

**Q6：可以修改或删除已提交的记录吗？**

可以。在历史数据的列表或日详情中进入 **记录编辑**，可修改数值、备注、时间，或删除该条记录。

**Q7：记录时间可以改吗？**

可以。录入或编辑记录时可校正 **记录时间**（`recorded_at`），便于补记漏记的数据。

**Q8：数据存在哪里？会同步到云端吗？**

数据默认 **仅保存在本机**，使用加密数据库（SQLCipher）存储。当前版本 **无账号体系、无云同步**。换机或卸载前请通过 CSV 导出自行备份。

**Q9：如何备份或导出数据？**

进入 **设置 → 导出 CSV**，选择日期范围后导出，通过系统分享保存到文件、邮件或云盘。

**Q10：如何彻底清除所有数据？**

进入 **设置 → 数据管理 → 清除所有数据**，输入「删除」确认。此操作不可恢复，请先导出备份。

### 日历与统计

**Q11：日历上的涨跌数字是怎么算的？**

显示的是该日数值相对 **上一有记录日** 的变化（如体重「比上次降 0.3 kg」），而非相对前一天。

**Q12：参考区间线是什么意思？**

在统计图表中，若你为指标设置了参考区间（如血压正常范围），图表会显示参考线供对照。**这不代表医学诊断结论**，仅供参考。

**Q13：年度热力图在哪里？**

**设置 → 年度热力**，可查看全年每日是否有记录的概览。

### 提醒与安全

**Q14：提醒不生效怎么办？**

1. 在 **设置 → 通知权限** 中授权通知。
2. 确认该指标在创建/编辑时已开启提醒并设置了时间。
3. iOS/Android 系统设置中检查是否禁止了记刻的通知。
4. 部分机型需在系统设置中允许「后台活动」或关闭省电限制。

**Q15：PIN 锁忘了怎么办？**

PIN 用于应用解锁，遗忘后通常需清除应用数据或重新安装（会丢失本地数据）。请务必牢记 PIN，或导出 CSV 后再操作。

**Q16：点击通知能直接录入吗？**

支持。点击记录提醒通知可跳转至对应指标的录入页（需系统与版本支持）。

### 健康同步与 Widget

**Q17：健康数据同步支持哪些平台？**

仅 **iOS**（Apple 健康）和 **Android**（Health Connect）支持。可导入体重、血压、心率等标准类型近 30 天数据；自定义指标仍保存在记刻本地数据库。

**Q18：桌面 Widget 如何使用？**

需在完成原生 Widget 配置后，今日进度会自动同步到桌面小组件。详见项目内 `platform/HOME_WIDGET.md` 或 **设置 → 桌面 Widget** 中的说明。

### 其他

**Q19：记刻需要联网吗？**

核心功能（记录、查看、统计、导出）**无需联网**。仅健康数据同步、系统分享等依赖系统能力的功能可能需要网络或权限。

**Q20：记刻能替代医院或体检报告吗？**

**不能。** 记刻仅供个人记录与趋势观察，不构成医疗诊断、治疗或用药建议。就诊时可将导出的 CSV 作为参考材料，最终判断须以专业医疗机构为准。
